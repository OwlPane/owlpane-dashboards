# Dashboards

Community dashboards  for Owlpane.

This is the public repository of dashboards for Owlpane. Dashboards are JSON files that can be imported into Owlpane to create a new dashboard.

## How to use

1. Download the json dashboard you want to use.
2. In Owlpane, click on the "Dashboards".
3. Click on the "Import" button.
4. Select the json file you downloaded.
5. Click on the "Import" button.

## How to contribute

If you are able to add a screenshot to the README of the dashboard you are adding, that would be great.

1. Fork this repository.
2. Create a new branch.
3. Add your dashboard to the appropriate `dashboards` folder.
4. Create a pull request.
